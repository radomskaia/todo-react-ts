# Список задач

Простой список задач на React + TypeScript, собранный на Vite. Сервер не нужен: задачи хранятся в `localStorage` браузера.

## Возможности

- Добавление задачи кнопкой «Добавить» или клавишей Enter. Пустую задачу или задачу из одних пробелов добавить нельзя, пробелы по краям обрезаются.
- Отметка задачи выполненной и обратно. Выполненные задачи зачёркнуты и приглушены.
- Удаление задачи.
- Фильтры «Все», «Активные», «Выполненные» и счётчик оставшихся задач.
- Сохранение в `localStorage`: задачи остаются после перезагрузки страницы. Повреждённые данные в хранилище не ломают приложение.
- Светлая, тёмная и системная тема. По умолчанию тема следует настройкам системы, выбранная вручную сохраняется в `localStorage` и применяется ещё до загрузки приложения, без мигания.
- Русский и английский интерфейс. По умолчанию язык берётся из настроек браузера, выбранный вручную сохраняется в `localStorage`.

## Запуск

Нужен Node.js 24.15 или новее (версия для CI указана в `.nvmrc`).

```sh
npm install
npm run dev
```

| `npm run test:coverage` | Тесты с отчётом о покрытии                       |
| `npm run typecheck`     | Проверка типов                                   |
| `npm run lint`          | ESLint                                           |
| `npm run stylelint`     | Stylelint для CSS                                |
| `npm run format`        | Форматирование Prettier                          |
| `npm run css:types`     | Генерация типов для CSS-модулей                  |
| `npm run knip`          | Поиск неиспользуемых файлов, экспортов и пакетов |

## Структура

```
src/
  App.tsx              — экран: переключатели, форма, фильтры, список, счётчик
  i18n/
    translate.ts       — список локалей и функция перевода с типизированными ключами
    messages.ts        — типы ключей и {плейсхолдеров}, выведенные из ru.ts
    locale.ts          — определение языка браузера, сохранение выбора
    I18nProvider.tsx   — текущий язык для всего приложения
    i18nContext.ts     — хук useTranslation()
    LanguageSwitcher.tsx — выбор языка: русский или английский
    locales/ru.ts, en.ts — тексты интерфейса
  theme/
    theme.ts           — список тем, сохранение, применение к <html>
    useTheme.ts        — текущая тема и её смена
    ThemeSwitcher.tsx  — переключатель светлой, тёмной и системной темы
  lib/
    storage.ts         — безопасные чтение и запись localStorage
  ui/
    Select.tsx         — выпадающий список
  todos/
    todo.ts            — тип задачи и фильтрация
    todoStorage.ts     — чтение и запись в localStorage
    useTodos.ts        — состояние задач и операции над ними
    TodoForm.tsx       — поле ввода и кнопка «Добавить»
    TodoFilters.tsx    — переключатель фильтров
    TodoList.tsx       — список или сообщение о пустом списке
    TodoItem.tsx       — задача: чекбокс, название, удаление
```

Компоненты получают функцию перевода из `useTranslation()` и вызывают `t('ключ', { параметры })`. Русская локаль — исходная: TypeScript проверяет по ней ключ и набор `{плейсхолдеров}`, а `satisfies Messages` не даёт другой локали пропустить ключ. Совпадение плейсхолдеров между локалями проверяет тест. Новая локаль — это файл рядом с `en.ts` и строка в `locales` в `translate.ts`.

Стили — CSS-модули рядом с компонентами. Типы для них (`*.module.d.css.ts`) генерируются автоматически при `npm run dev` или командой `npm run css:types` и хранятся в репозитории.
